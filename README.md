# 📊 Student Grade Tracker — Python
**v2 — Upgraded**

A Python console application for tracking and analysing student grades with persistent JSON storage.

---

## ✨ What's New in v2.0
- **Edit a grade** — update any existing grade for a student
- **Remove a grade** — delete a specific grade from a student's record
- **Remove a student** — delete a student with a confirmation prompt
- **Export report** — save a full grade report to `grade_report.txt`
- **Grade distribution** — visual bar chart showing how many A/B/C/D/F grades in the class
- **Top performer** — highlights the highest-averaging student in class stats
- **Cleaner output** — improved formatting and emoji indicators throughout

## 📋 Original Features
- Add students and record multiple grades
- Per-student summaries — average, letter grade, highest and lowest
- View all students with averages
- Class statistics
- Persistent JSON storage

---

## 🚀 How to Run
```bash
python grade_tracker.py
```

---

## 📁 Structure
```
├── grade_tracker.py    # Main app — GradeTracker class and menu
├── grades_data.json    # Auto-generated — stores all student data
└── grade_report.txt    # Generated on export
```
